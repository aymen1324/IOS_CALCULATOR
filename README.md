🍎 iOS Calculator

A modern calculator inspired by the iPhone Calculator, built with HTML, CSS, and JavaScript.

✨ Features

- Basic arithmetic operations
- Percentage ("%")
- Plus / Minus ("+/-")
- Repeated equals
- Thousands separator formatting
- Smart backspace
- Division-by-zero protection
- Responsive iPhone-inspired UI
- Clean, refactored JavaScript architecture

🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

🚀 Run Locally

git clone https://github.com/YOUR_USERNAME/IOS_Calculator.git
cd IOS_Calculator

Open "index.html" in your browser.
